# nano ベース

> ステータス: 合意済み（2026-09-27）

GNU nano の操作感のベース（`plugins/nano`、プラグイン名 `nano`）。[base.md](base.md) の「どこまで再現するか」に従い、指が覚えている操作が期待どおり動くことを目標にする。`[core] base = "nano"` で使う。

## 編集のモデル

- モードはない。修飾のない文字は、そのままカーソルの位置に入る。
- カーソルは文字と文字の間の点（幅 0 の選択）。複数のカーソルは使わない。
- `M-A` でマークを置くと、マークからカーソルまでが選択になり、移動するとカーソルの側が伸びる。マークはコアの選択の anchor として持つので、ほかのプラグインの編集にも合わせて動く。
- カットバッファは 1 つ。`^K` を続けて押すと、切り取った行が足されていく。
- undo は、続けて打った文字を 1 手にまとめる。
- `Esc` のあとのキーは、`Alt` を押しながらと同じ（nano と同じ）。

## キー

| キー | 動作 |
|------|------|
| `^G` | コアのメニュー（nano ではヘルプ。`plugin.toml` の `menu-key`） |
| `^X` | 終了。未保存なら「Save modified buffer?」と聞き、`Y` / `N` / `^C` で答える |
| `^O` | 書き出し。「File Name to Write:」に今のパスを入れて聞く。別の名前なら、そこへ保存し以後その名前にする |
| `^R` | ファイルを挿入する（作業ディレクトリの中のもの） |
| `^W` / `M-W` / `M-Q` | 検索（文字どおり。正規表現ではない）/ 次 / 前。端で折り返す |
| `^\` | 置き換え。探す文字と置き換える文字を聞き、すべて置き換えて数を出す |
| `^K` / `^U` / `M-6` | 行（マークがあれば選択）の切り取り / 貼り付け / コピー |
| `M-A` | マークを置く・外す |
| `M-U` / `M-E` | undo / redo |
| `^C` | カーソルの位置（行、列、文字）を出す |
| `^_`（`^/`） | 指定した行（と列）へ。「Enter line number, column number:」 |
| `^T` | コマンドの一覧（`picker.commands`。nano では Execute） |
| `^A` `^E` / `Home` `End` | 行頭 / 行末 |
| `^P` `^N` `^B` `^F` / 矢印 | 上下左右 |
| `^Y` `^V` / `PageUp` `PageDown` | 1 画面上 / 下 |
| `^Space` `M-Space` / `^→` `^←` | 次 / 前の単語 |
| `M-\` `M-/` | ファイルの先頭 / 末尾 |
| `M-]` | 対応する括弧へ |
| `^H` `Backspace` / `^D` `Delete` | 前 / 後ろの 1 文字を消す。マークがあれば選択を消す |
| `M-X` | 下の 2 行のキーの案内を出す・隠す（最初は出す） |

- 入力欄（`^W` などの問い）では、`^C` で取り消す。`^A` `^E` `^B` `^F` `^H` `^D` が効き、`^K` で中身を消す。ほかはコアの既定（[plugin-api.md](plugin-api.md) の「入力欄」）。
- 補完の一覧などが開いているときは、上下と `^P` `^N` で選び、`Tab` と `Enter` で決める。

## リーダー

nano の `M-` のうち nano 自身が使わないものを、プラグインのキーの置き場にする。プラグインの `[keys]` の `f` は `M-F`、`c d` は `M-C` のあと `d`。nano 自身が使う `M-A` `M-E` `M-Q` `M-U` `M-W` `M-X` `M-6` `M-]` `M-\` `M-/` `M-Space` は取らない。

## 設定

`plugins/nano.toml` の `[settings.keys.global]` で上書きする。右辺はコマンドの名前か、nano の機能の名前（nanorc の `bind` で使う名前: `exit`、`writeout`、`insert`、`whereis`、`replace`、`cut`、`paste`、`copy`、`mark`、`undo`、`redo`、`location`、`gotoline`、`execute` など）。

```toml
[settings.keys.global]
"C-s" = "writeout"
"C-q" = "exit"
```

## nano との違い

- `^G` はヘルプではなく nib のメニュー。
- `^T` は外部コマンドではなく nib のコマンドの一覧。
- `^\` は 1 つずつ確かめずに、すべて置き換える。
- `^J`（整形）、`M-#`（行番号）、スペルチェックなどはない。
- 上端のタイトルの行はない。ファイル名はステータスラインに出る。
