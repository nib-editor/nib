# コアメニュー

> ステータス: 合意済み（2026-09-29）。nib 0.12.0 で入れる。

メニューのキー（既定は Ctrl-g、[architecture.md](architecture.md) の「入力」）で開く、コアが自分で描くメニュー。プラグインの様子を見て、再起動、無効化、追加、削除をし、エディタを終える。ベースが壊れていても開けるように、プラグインを介さない。

0.11 までは、画面の下にプラグインを 1 行ずつ並べ、キーの案内をステータスラインに出していた。これを、helix のファインダーのように画面の真ん中の枠に出し、文字を打って絞り込めるようにする。

## なぜ変えるか

- 1 行に版、時間制限、遅い呼び出しの数、状態、権限を詰めていたので、最後のエラーのように長いものが切れて読めなかった。
- 操作が `r` `w` `q` `a`、プラグインごとの `r` `d` `l` `u` `x` という 1 打のキーで、何ができるかはステータスラインの案内を読むしかなかった。
- 標準プラグインだけで 15 を超え、番号（`1`〜`9`）で選べるのは前のほうだけだった。

## 形

```
╭─ nib ──────────────────────────────────────────────────────────────╮
│ > vi                                                          2/23 │
├──────────────────────────────────┬─────────────────────────────────┤
│ vim      0.1.0  base, not in use │ vim 0.1.0                       │
│ Save all and quit                │ A base: Vim's keys, checked     │
│                                  │ against Neovim.                 │
│                                  │                                 │
│                                  │ state     base, not in use      │
│                                  │ can       nothing beyond the    │
│                                  │           editor                │
│                                  │ limit     100ms                 │
│                                  │ settings  plugins/vim.toml      │
╰─ ↑↓ move · enter choose · esc back ────────────────────────────────╯
```

- 画面の真ん中に、枠のある箱を出す。幅は画面の 9 割（最大 120 桁）、高さは 8 割（最大 30 行）。本文とステータスラインの上に重ねるので、ビューの大きさは変わらない。
- 上の行が絞り込みの欄。右に、絞り込んだ数と全体の数。
- 左が一覧、右が選んでいる項目の詳しい中身。箱の幅が 72 桁に満たないときは、右を出さずに一覧だけにする。
- 下の枠線に、その場で効くキーの案内を書く。
- 題（上の枠線）は、今いる場所: `nib`、`nib › vim`、`Choose a base`。

### 一覧の項目

最初の一覧には、プラグインと、エディタ全体の操作を並べる。プラグインが先（このメニューのいちばんの役目は、おかしなプラグインを直すことなので）。

| 項目 | すること |
|------|----------|
| 各プラグイン | そのプラグインの操作の一覧へ |
| Open config.toml | `config.toml` を開く（`config.open`） |
| Open the settings directory | 設定のディレクトリを開く（`config.open-directory`、[files.md](files.md)） |
| Reload the settings | 設定を読み直す（`config.reload`） |
| Add a plugin | 入れるものを打つ欄へ（入れられるときだけ） |
| Restart all plugins | プラグインを全部再起動する |
| Save all and quit | 全部保存して終える |
| Quit | 終える。保存していない変更があれば聞く |

プラグインの行は、名前、版、状態（`running`、`running, the base`、`base, not in use`、`disabled`、`waiting`、`languages`、エラー）。エラーの行は `ui.error` の色にする。

プラグインを選ぶと、そのプラグインの操作が一覧になる（題は `nib › <name>`）。右は、同じくそのプラグインの詳しい中身。

| 項目 | すること |
|------|----------|
| Restart | 再起動する |
| Disable / Enable / Use as the base | 止める・動かす・ベースにする |
| Reload from disk | ディレクトリから読み直す（`--plugin` で読んだものだけ） |
| Update | 新しい版を探して入れる（入れたものだけ） |
| Remove | 消す（入れたものだけ） |
| Open its settings | `plugins/<name>.toml` を開く |

### 詳しい中身

プラグインでは:

- 名前と版、`description`（あれば）
- 状態。最後のエラーは全文を折り返して出す。
- `can`: 権限（なければ `nothing beyond the editor`）
- `limit`: 1 回の呼び出しの時間制限
- `slow`: 時間のかかった呼び出しの数
- `settings`: 設定のファイル（`plugins/<name>.toml`。なければ `none yet`）

操作では、何をするかの説明を 1〜2 文で。

`description` は、`plugin.toml` に足す任意の項目（1 行の説明）。標準プラグインには全部書く。ベースを選ぶときの手がかりにもなる。

### キー

| キー | すること |
|------|----------|
| 文字 | 絞り込みの欄に打つ |
| `Backspace` / `Ctrl-u` | 1 文字消す / 全部消す |
| `↑` `↓`、`Ctrl-p` `Ctrl-n`、`Shift-Tab` `Tab` | 選ぶ項目を動かす |
| `PageUp` `PageDown` | 1 画面ぶん動かす |
| `Enter` | 選ぶ |
| `Esc` | 1 つ戻る。最初の一覧では閉じる |
| メニューのキー | 閉じる |

- 絞り込みは、大文字と小文字を区別せず、打った文字が順に含まれるもの（`rsa` で `Restart all`）。合った文字を `ui.popup.key` の色にする。
- 並びは、打ったもので始まるもの、打ったものをそのまま含むもの、飛び飛びに含むもの、の順。それぞれの中は一覧の順のまま。`quit` で `Save all and quit` より `Quit` が先に来るように。細かい点数で並べ替えないのは、項目が 30 に満たず、場所があまり動かないほうが探しやすいため。
- `j` `k` で動かしたり、番号で選んだりするのはやめる。文字はすべて絞り込みに使う。
- 「ほかのキーで閉じる」もやめる。打ち間違いは絞り込みに入るだけで、何も起きない。

### 確かめるとき

終える（変更がある）、消す、権限の増える更新、入れる、の 4 つは、箱の中に問いと中身を書き、`y` で進み、ほかのキーで戻る（今と同じ）。

### 入れるものを打つ欄

`Add a plugin` では、絞り込みの欄が入れるものを打つ欄になる（`add: ` のあとに打つ）。右には、打てるもの（一覧の名前、`owner/repo[@tag]`、URL、ファイル）を書く。`Enter` で取りに行き、`Esc` で戻る。

### ベースを選ぶ（最初の起動）

ベースが 2 つ以上あるときの最初の起動で、同じ箱に `Choose a base` としてベースを並べる。右には、そのベースの `description`。`Enter` で選び、`Esc` は今のベースのまま（それも答えとして `config.toml` に書く。今と同じ）。

## コアの中の形

- メニューの箱は、描画の最後（ポップアップより上）に重ねる。ステータスラインは、ふつうの中身に戻る。
- 開いている間の端末のカーソルは、絞り込みの欄に置く（バーの形）。
- 一覧の項目は、状態から毎回作る。選んでいる位置は、絞り込んだ一覧の中の番号で持つ。絞り込みの文字が変わったら、先頭に戻す。
- 一覧が箱に入りきらないときは、選んでいる項目が見えるところまでずらす。

## 入れないもの

- picker（ファイルやコマンドのファインダー）を同じ箱に出すこと。プラグインが真ん中の箱を出せる UI 部品を API に足すことになるので、別に考える。
- 点数による並べ替え。
- プラグインの `keys`（リーダーの下のキー）の一覧を詳しい中身に出すこと。
