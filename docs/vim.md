# vim ベース

> ステータス: 実装済み（2026-09-28）。レビュー待ち。

Vim の操作感のベース（`plugins/vim`、プラグイン名 `vim`）。[base.md](base.md) の「どこまで再現するか」に従い、指が覚えている操作が期待どおり動くことを目標にする。`[core] base = "vim"` で使う。

Vim と Neovim で既定が違うところは、Neovim に合わせる（`nvim --clean` と比べるため）。`Y` は `y$`、`gg` `G` `dd` `:5` はカーソルの列を保つ（`nostartofline`）、挿入モードの Enter は前の行のインデントを引き継ぐ（`autoindent`）、Backspace は行頭やインデントを越えて消せる（`backspace=indent,eol,start`）、`J` は `.` のあとにも空白を 1 つだけ入れる（`nojoinspaces`）。

## 編集のモデル

- モードは normal、insert、replace、visual（文字、行、矩形）。モードはステータスラインの左に出す（` NORMAL ` など）。打ちかけのキー（`2d` など）とマクロの記録中（`recording @q`）は右に出す。
- normal モードのカーソルは、文字の上の点（幅 0 の選択）で、ブロックの形で描く。行にテキストがあれば、行末の改行の上には置かない。ほかのプラグインが範囲を選んだり、カーソルを改行の上に置いたりしたら、次のコマンドの前にその位置の文字の上の点に戻す。
- visual モードの両端（始めた位置とカーソル）は、コアの位置の印（`buffer.set-marks`）に置き、そこから毎回選択を描く。ほかのプラグインの編集で文字がずれても、両端は同じ文字を指し続ける。矩形は行ごとの範囲の組で描く。
- キーは、コマンドとして読み切れるまでためてから実行する（`["x][count]` に続けて、コマンドか、オペレーター・カウント・モーションかテキストオブジェクト）。読めないキーの列は捨てる。
- 端末に貼り付けたものは、Neovim と同じく、挿入モードでは打ったように、normal モードでは `p` のようにカーソルの後ろに、visual モードでは選択を置き換えて入れる。コマンドラインでは欄に入る。
- undo は、normal モードのコマンド 1 つを 1 手にする。挿入モードは、入ったコマンドから Esc までを 1 手にする（`cw` の削除と打った文字も 1 手）。矢印キーで動くと、そこから新しい 1 手になる。
- `.` は、最後の変更をコマンドとして持ち、挿入モードで打ったキーも一緒に持つ。カウントを付けると、元のカウントの代わりになる。
- マクロ（`q` `@`）はキーの列として持つ。`@` の途中でモーションが失敗したら（`j` が最終行で動けないなど）、そこで止まる。
- マーク（`ma` `'a` `` `a ``）、`''`、`'<` `'>`、`'.`（最後の変更）、`'^`（挿入を抜けた位置）、ジャンプリスト（Ctrl-o、Ctrl-i）は、コアの位置の印に置く。ほかのプラグインの編集（LSP の整形など）でも正しい場所を指し続ける。`A`〜`Z` のマークは、どのファイルのものかを覚えておき、飛ぶときにそのファイルを開く。ジャンプリストはファイルごと。

## キー

### モーション

| キー | 動作 |
|------|------|
| `h` `j` `k` `l`、矢印 | 左下上右。`j` `k` は列を保つ（`$` のあとは行末を保つ） |
| `w` `W` `b` `B` `e` `E` `ge` `gE` | 単語。空行も 1 語。オペレーターと使うときの行末の扱い（`dw` が行を越えない、`cw` が `ce` になる）も Vim と同じ |
| `0` `^` `$` `g_` `|` | 行の中 |
| `gg` `G` `+` `-` `_` Enter | 行へ。`{count}G` は行番号、`{count}%` はファイルの割合 |
| `f` `t` `F` `T` `;` `,` | 行の中の文字。`;` は `t` のあと隣の文字を飛ばす |
| `%` | 対応する括弧（カーソルの後ろで最初に見つかった括弧から） |
| `{` `}` | 段落（空行） |
| `H` `M` `L` | 画面の上・中・下 |
| `/` `?` `n` `N` `*` `#` `g*` `g#` | 検索。端で折り返し、そのことを知らせる |
| `'a` `` `a `` `''` | マーク |

オペレーターと使うとき、排他的なモーションが行頭で終わる場合は前の行の終わりまでにし、始まりがインデントの中なら行単位にする。行の途中から行末までを消す `d` で、前も後ろも空白だけなら行単位にする。どちらも Vim の規則のとおり。

### オペレーターとテキストオブジェクト

| キー | 動作 |
|------|------|
| `d` `c` `y` `>` `<` `g~` `gu` `gU` | オペレーター。2 回で行（`dd`、`g~~`、`gUgU`） |
| `iw` `aw` `iW` `aW` | 単語 |
| `ip` `ap` | 段落（空白だけの行も区切り） |
| `i(` `a(` `ib` `i{` `iB` `i[` `i<` | 括弧。カウントで外側へ。行をまたぐ中身は行単位 |
| `i"` `a"` `i'` `i`` ` | 引用符（行の中。カーソルの後ろの組でもよい） |

| キー | 動作 |
|------|------|
| `x` `X` `s` `S` `C` `D` `Y` | `dl` `dh` `cl` `cc` `c$` `d$` `y$` |
| `p` `P` | 貼り付け。行、文字、矩形 |
| `J` `gJ` | 行の連結 |
| `r` `R` `~` | 置き換え。`r` Enter は改行に |
| `i` `a` `I` `A` `gI` `o` `O` `gi` | 挿入モードへ。カウントで打った文字を繰り返す |
| `u` Ctrl-r `.` | undo、redo、繰り返し |
| `v` `V` Ctrl-v `gv` | visual モード |
| `"x` | レジスタ（下の「レジスタ」） |
| `q` `@` `@@` `@:` | マクロ、最後の `:` の繰り返し |
| `m` | マーク |
| Ctrl-o Ctrl-i（Tab） | ジャンプリスト |
| `zz` `zt` `zb` Ctrl-e Ctrl-y Ctrl-d Ctrl-u Ctrl-f Ctrl-b | スクロール |
| Ctrl-a Ctrl-x | 数を足す・引く（10 進、`0x`、`0b`） |
| `gd` Ctrl-] / `K` | 定義へ（`lsp.definition`）/ ホバー（`lsp.hover`） |
| Ctrl-w と `v` `s` `w` `h` `j` `k` `l` `q` `c` `o` | ビューの分割と移動 |
| `ZZ` `ZQ` `&` | `:x`、`:q!`、`:&&` |
| `:` | コマンドライン |
| Ctrl-g | コアのメニュー（Vim ではファイルの情報。`plugin.toml` の `menu-key`） |

### visual モード

モーションとテキストオブジェクトで広げる。`o` `O` で端を入れ替える。`d` `x` `X` `D` `y` `Y` `c` `s` `C` `S` `R` `>` `<` `~` `u` `U` `g~` `gu` `gU` `J` `gJ` `r` `p` `P` `I` `A` `:` が効く。矩形の `I` `A` はすべての行に打ち、`A` は短い行を空白で伸ばす。

### 挿入モード

文字、Enter（インデントを引き継ぎ、何も打たずに抜けたらそのインデントを消す）、Tab、Backspace、Delete、矢印、Home、End。Ctrl-w（単語）と Ctrl-u（行）は、挿入を始めた位置で一度止まる。Ctrl-t と Ctrl-d でインデント、Ctrl-r でレジスタ、Ctrl-v で次のキーをそのまま、Ctrl-o で normal モードのコマンドを 1 つ。Ctrl-n と Ctrl-p は補完（`lsp.complete`）を開き、一覧が出ていれば選ぶ。Esc、Ctrl-[、Ctrl-c で抜ける。

## レジスタ

無名（`"`）、`a`〜`z`（`A`〜`Z` は足す）、`0`（最後のヤンク）、`1`〜`9`（行の削除や行をまたぐ削除、`%` `/` `n` `{` `}` などでの削除がずれていく）、`-`（行の中の小さな削除）、`_`（捨てる）、`+` と `*`（システムのクリップボード。`clipboard` の権限を使う）。

## コマンドライン

`:` のあとは Vim のアドレス（`%`、`.`、`$`、数、`'a`、`/pat/`、`?pat?`、`+n`、`-n`、`,` と `;`）と、次のコマンドを読む。カウントを付けた `:` は `:.,.+(count-1)` を入れて開く。

| コマンド | 動作 |
|----------|------|
| `:{n}` | 行へ |
| `:s/pat/rep/[gine]` `:&` `:&&` | 置き換え。`&` と `\0` は一致した文字、`\1`〜`\9` はグループ、`\r` は改行 |
| `:d` `:y` `[x] [count]` | 行の削除とヤンク |
| `:j[!]` `:>` `:<` `:m` `:t` `:co` | 行の連結、インデント、移動、複製 |
| `:g/pat/cmd` `:g!` `:v` | 一致する（しない）行ごとにコマンド |
| `:norm[al] keys` | 行ごとに normal モードのキー |
| `:w [path]` `:wq` `:x` `:q[!]` `:qa` `:wa` `:up` | 保存と終了 |
| `:e path` `:sp` `:vs` `:on` `:clo` `:bn` `:bp` `:bd[!]` | ファイルとビュー |
| `:reg` | レジスタの中身を `*registers*` に出す（下に分割して。`q` で閉じる） |
| `:noh` | 何もしない（検索の強調がないため） |
| `:config` `:config-reload`、`:lsp.definition` のような名前 | nib のコマンド（[base.md](base.md) の「コマンドを名前で呼ぶ」） |

コマンドラインでは Ctrl-w、Ctrl-u、Ctrl-b、Ctrl-e、Ctrl-h、Ctrl-r（レジスタ）、上下と Ctrl-p Ctrl-n（履歴）、Tab（コマンドの名前の補完）が効く。ほかはコアの既定（[plugin-api.md](plugin-api.md) の「入力欄」）。

検索のパターンは Vim の書き方（magic）で書き、コアの正規表現に直して探す。`\(` `\|` `\+` `\=` `\{n,m}` `\{-}` `\<` `\>` `\s` `\d` `\w` `\a` `\l` `\u` `\x` `\h` `\_s` `\_.` `\v` `\V` `\c` を読む。

## リーダー

`<leader>` は既定で Space。プラグインの `[keys]` の `f` は `Space f`、`c d` は `Space c d`。`plugins/vim.toml` の `leader` で変えられる（`leader = ","`）。Vim の Space（右へ動く）は、リーダーに譲る。

## プラグインのバッファのキー

プラグインのバッファ（[plugin-buffers.md](plugin-buffers.md)）が決めたキーは、normal モードでは vim のキーより先に効く。ただし、次のキーは vim のまま。プラグインの作者は、これを避けてキーを選ぶ（`Enter`、`q`、`s`、`d` のような、一覧の中では使わないキー）。

- 動きと数: `h` `j` `k` `l` `w` `W` `b` `B` `e` `E` `0`〜`9` `^` `$` `g` `G` `f` `F` `t` `T` `;` `,` `%` `{` `}` `H` `M` `L`、矢印、`Home` `End` `PageUp` `PageDown`
- 検索: `/` `?` `n` `N` `*` `#`
- コマンドライン、visual モード、コピー、印: `:` `v` `V` `y` `"` `'` `` ` `` `m` `z`
- Ctrl: `C-w`（ウィンドウ）、`C-d` `C-u` `C-f` `C-b` `C-e` `C-y`（スクロール）、`C-o` `C-i`（ジャンプ）、`C-v`、`C-[` `C-c`
- `Esc` とリーダー

`plugins/vim.toml` の `[settings.keys.*]` で決めたキーは、バッファのキーより先に効く。

## 設定

`plugins/vim.toml` の `[settings.keys.normal]`、`[settings.keys.insert]`、`[settings.keys.visual]` で上書きする。右辺はコマンドの名前か、Vim のマッピングの右辺と同じキーの列（`<CR>` `<Esc>` `<C-w>` `<lt>` などを読む）。右辺のキーは、ほかのマッピングを通さない（`noremap` と同じ）。

```toml
leader = ","

[settings.keys.normal]
Y = "yy"
"C-s" = ":w<CR>"
"C-p" = "picker.files"
```

## 本物との比べ方

`tui/tests/compare.rs` が、`plugins/vim/compare.toml` の各ケースのキーを `nvim --headless --clean` と nib に流し、テキストとカーソルの位置を比べる（[base.md](base.md) の「どこまで再現するか」）。nvim がなければ飛ばす（CI では入れて、必ず走らせる）。

- 2026-09-28 の時点で 328 ケース。325 が Neovim 0.12.5 と同じで、3 つは下の違い。
- 違うと分かっているケースは `differs` に理由を書く。同じになったら、テストが `differs` を外すように言う。

## Vim との違い

- インデントの幅は、nib の `indent` の設定（`>>`、`:>`、Ctrl-t、Tab）。Vim の `shiftwidth` と `expandtab` は読まない。
- 行単位の visual で `A` を押すと、最後の行の末尾に追記する。Neovim は前に実行したコマンドの状態によって、最後の文字の前に入れることがある。
- `:s` の置き換えで `\u` `\U` `\l` `\L` は使えない。パターンの `\zs` `\ze` と `\%` の仲間も使えない（コアの正規表現にない）。
- 検索の強調（`hlsearch`）と、打っている間に動く検索（`incsearch`）はない。
- `.` は visual モードの操作を繰り返さない。
- マクロはキーの列として持つので、`"qp` で中身を貼り付けて直すことはできない（`"qp` はヤンクしたレジスタだけ）。
- 折りたたみ、`=`、`gq`、`!`、タグ（`it` `at`）、文（`(` `)` `is` `as`）、変更リスト（`g;`）、`:set` はない。
- 挿入モードの Ctrl-n と Ctrl-p は、単語の補完ではなく LSP の補完を開く。
