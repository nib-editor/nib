# Emacs ベース

> ステータス: 実装済み（2026-09-28）。レビュー待ち。

GNU Emacs の操作感のベース（`plugins/emacs`、プラグイン名 `emacs`）。[base.md](base.md) の「どこまで再現するか」に従い、指が覚えている操作が期待どおり動くことを目標にする。`[core] base = "emacs"` で使う。

`emacs -Q`（設定なし）の既定に合わせる。`transient-mark-mode` は有効、`delete-selection-mode` は無効、`electric-indent-mode` は有効。インデントに tab を使うか（`indent-tabs-mode`）は nib の `indent` の設定に、tab の幅（`tab-width`）は nib の `tab-width` に従う。

## 編集のモデル

- モードはない。修飾のない文字は、そのままポイント（カーソル）の位置に入る。
- ポイントは文字と文字の間の点（幅 0 の選択）。複数のカーソルは使わない。
- マークとマークリングは、コアの位置の印（`buffer.set-marks`）にバッファごとに置く。ほかのプラグインの編集（LSP の整形など）でも正しい場所を指し続ける。
- リージョンが有効な間は、マークからポイントまでを選択として描く（anchor がマーク、head がポイント）。バッファを変えるコマンドのあとと `C-g` で無効になる。Shift を押しながらの移動（`S-<right>`、`C-S-f` など）は、その間だけ有効なリージョンを作る。
- ほかのプラグインが選択を変えたら、その head をポイントとして受け取る。
- 前置き引数は `C-u`（4、16、…）、`C-u` のあとの数と `-`、`M-0`〜`M-9`、`C-0`〜`C-9`、`M--`、`C--`。打っている間は右下に出す（`C-u 4-`）。
- 続けて打った文字は、20 文字までを undo の 1 手にまとめる（Emacs の amalgamation と同じ）。`C-d` と `DEL` も同じ。ほかのコマンドは 1 つで 1 手。
- `Esc` のあとのキーは `Meta` を押しながらと同じ。`Esc Esc Esc` は `keyboard-escape-quit`。
- コマンドの失敗（バッファの端で `C-f` など）は、エコー領域に出す（`End of buffer`）。キーボードマクロはそこで止まる。

## キルリングとクリップボード

- キルリングは 120 件まで。キルのコマンドが続くと、1 つの項目に足していく（後ろ向きのキルは前に足す）。`M-w` は足さない側の始まりになる（Emacs と同じ）。
- キルはシステムのクリップボードにも置く（`select-enable-clipboard` と同じ。`clipboard` の権限を使う）。yank のとき、クリップボードに nib の外で置かれた文字があれば、先にキルリングへ入れる。
- `C-y` はポイントに入れ、入れた範囲の始めにマークを置く（有効にはしない）。`C-u C-y` はポイントを始めに置く。`C-u n C-y` は n 番目の項目。`M-y` は直前の yank を 1 つ前の項目に入れ替える。
- 矩形のキル（`C-x r k`）は、別の置き場（`killed-rectangle`）に入る。`rectangle-mark-mode` での `C-w` と `M-w` は、矩形をキルリングに入れ、`C-y` で矩形として入る。

## キー

### 移動

| キー | 動作 |
|------|------|
| `C-f` `C-b` `C-n` `C-p`、矢印 | 文字、行。`C-n` `C-p` は列を保つ |
| `C-a` `C-e`、`Home` `End` | 行頭、行末 |
| `M-m` | インデントのあと |
| `M-f` `M-b`、`C-<right>` `C-<left>`、`M-<right>` `M-<left>` | 単語（英数字の並び。`_` は区切り） |
| `M-a` `M-e` | 文（`sentence-end-double-space` の既定どおり、`.` のあとに空白 2 つか行末で終わる） |
| `M-{` `M-}`、`C-<up>` `C-<down>` | 段落（空行） |
| `C-M-f` `C-M-b` `C-M-u` `C-M-d` | S 式（括弧の対応、文字列、記号の並び） |
| `C-M-a` `C-M-e` | 関数の始め、終わり（tree-sitter の関数。文法がなければ列 0 の `(`） |
| `M-<` `M->`、`C-<home>` `C-<end>` | バッファの先頭、末尾。マークを置く。前置き引数は 10 分の n の位置 |
| `C-v` `M-v`、`PageDown` `PageUp` | 1 画面 |
| `C-l` | 画面の中・上・下にポイントの行を置く |
| `M-r` | 画面の中・上・下の行へ |
| `M-g g` `M-g M-g` / `M-g c` / `M-g TAB` | 行、文字の位置、列へ |

### 編集

| キー | 動作 |
|------|------|
| `RET` | 改行し、前の行のインデントを引き継ぐ（`electric-indent-mode`）。抜ける行の末尾の空白は消す |
| `C-j` | 改行だけ |
| `C-o` | ポイントの後ろに改行を入れる |
| `TAB` | `indent-relative`: 前の空でない行の、次のインデントの位置まで空白を入れる。なければ次のタブの位置へ |
| `C-x TAB` | リージョンの行をインデントする。前置き引数で幅を決め、なければ `<left>` `<right>`（1 列）と `S-<left>` `S-<right>`（タブの位置）で動かす |
| `C-d` `DEL`、`<deletechar>` | 後ろ・前の 1 文字。`DEL` と `<deletechar>` はリージョンが有効ならリージョンを消す |
| `C-k` | 行末までキル。行末か、後ろが空白だけなら改行まで。`C-u n` で n 行、`C-u 0` で行頭まで、負の数で前の行へ |
| `C-S-<backspace>` | 行ごとキル |
| `M-d` `C-<delete>` / `M-DEL` `C-<backspace>` | 単語をキル（後ろ / 前） |
| `M-k` `C-M-k` | 文、S 式をキル |
| `M-z` | 指定した文字までキル（文字も含む） |
| `C-w` `M-w` | リージョンをキル、コピー。マークがなければ「The mark is not set now」 |
| `C-y` `M-y` | yank、yank の入れ替え |
| `C-t` `M-t` `C-x C-t` | 文字、単語、行の入れ替え |
| `M-u` `M-l` `M-c` | 単語を大文字、小文字、頭文字だけ大文字に。負の数で前の単語 |
| `C-x C-u` `C-x C-l` | リージョンを大文字、小文字に（Emacs のように無効にはしていない） |
| `M-\` `M-SPC` `M-^` `C-x C-o` | 空白を消す、1 つにする（続けて押すと消す）、前の行とつなぐ、空行を 1 つにする |
| `C-q` | 次のキーをそのまま入れる |
| `M-/` | 単語の補完（`dabbrev-expand`。前、後ろの順に探し、続けて押すと次の候補） |
| `C-M-i` `M-TAB` | 補完（`lsp.complete`） |
| `C-/` `C-_` `C-x u` / `C-?` `C-M-_` | undo / redo（Emacs 28 の `undo-redo`） |

### マーク

| キー | 動作 |
|------|------|
| `C-SPC` `C-@` | マークを置き、リージョンを有効にする。2 度続けると無効にする |
| `C-u C-SPC` | マークへ戻り、マークリングを 1 つ回す |
| `C-x C-x` | ポイントとマークを入れ替え、リージョンを有効にする（`C-u` を付けると有効にしない） |
| `C-x h` `M-h` `M-@` `C-M-SPC` `C-M-h` | バッファ、段落、単語、S 式、関数をマークする。`M-@` と `C-M-SPC` は続けると広げる |
| `C-x SPC` | `rectangle-mark-mode`。矩形を行ごとの範囲で描く |
| `C-g` | リージョンを無効にし、打ちかけのキーと前置き引数を捨てる |

### 検索と置き換え

| キー | 動作 |
|------|------|
| `C-s` `C-r` | インクリメンタル検索。打つたびに次の一致へ動く。`C-s` `C-r` で次・前（端で失敗し、もう一度押すと折り返す）、何も打たずに `C-s` で前回の文字列、`DEL` で 1 手戻る、`C-w` でポイントの単語を足す、`C-y` でキルを足す、`RET` で終わる、`C-g` で戻る（一致しない部分があれば、その部分を消す）。ほかのキーは検索を終えてから、そのキーとして動く。検索を始めた位置にマークを置く |
| `C-M-s` `C-M-r` | 正規表現で検索する |
| `M-%` `C-M-%` | 問い合わせながら置き換える（文字どおり、正規表現）。`y` `SPC` 置き換え、`n` `DEL` 飛ばす、`!` 残りをすべて、`.` 置き換えて終わる、`,` 置き換えてとどまる、`q` `RET` 終わる、`C-g` やめる |
| `M-x replace-string` `M-x replace-regexp` | 問い合わせずに置き換える |

- 大文字を含まない文字列は、大文字と小文字を区別しない（`case-fold-search` と `search-upper-case`）。置き換えでは、一致した文字が大文字だけなら置き換える文字も大文字に、頭文字が大文字なら頭文字を大文字にする。
- リージョンが有効なら、置き換えはリージョンの中だけ。
- 正規表現は Emacs の書き方で書き、コアの正規表現に直して探す。`\(` `\)` `\(?:` `\|` `\{n,m\}` `\<` `\>` `\b` `\w` `\W` `\s-` `\sw` `\_<` `\_>` `` \` `` `\'` と `[[:space:]]` などを読む。置き換える文字では `\&`（一致した文字）と `\1`〜`\9`（グループ）を読む。
- 正規表現の isearch で、打ちかけの `t\(` のように正規表現になっていない間は、失敗にせず前の一致にとどまる（`(incomplete input)`）。

### 矩形とレジスタ

| キー | 動作 |
|------|------|
| `C-x r k` `C-x r M-w` `C-x r d` `C-x r y` | 矩形のキル、コピー、削除、yank |
| `C-x r o` `C-x r c` `C-x r t` `C-x r N` | 空白で押し出す、空白で消す、文字で置き換える、行番号を入れる |
| `C-x r s` `C-x r x` / `C-x r i` `C-x r g` | リージョンをレジスタへ（`C-u` で消す）/ 入れる |
| `C-x r r` | 矩形をレジスタへ |
| `C-x r SPC` / `C-x r j` | ポイントをレジスタへ / 飛ぶ（ファイルを覚え、別のファイルなら開く） |
| `C-x r n` `C-x r +` | 数をレジスタへ、足す（`C-x r i` で入れる） |

### キーボードマクロと繰り返し

| キー | 動作 |
|------|------|
| `C-x (` `F3` / `C-x )` `F4` | 記録を始める、終える。記録中は右下に `Def` を出す |
| `C-x e` `F4` | 最後のマクロを実行する。続けて `e` で繰り返す。前置き引数で回数、0 は失敗するまで |
| `C-x z` | 最後のコマンドを繰り返す。続けて `z` で繰り返す |

### ファイル、バッファ、ウィンドウ

| キー | 動作 |
|------|------|
| `C-x C-s` / `C-x s` | 保存（変更がなければ「(No changes need to be saved)」）/ 変更のあるファイルを 1 つずつ聞いて保存する（`y` `n` `!` `q`） |
| `C-x C-w` / `C-x C-f` / `C-x i` | 別名で保存 / ファイルを開く / ファイルを挿入する。ファイル名は `TAB` で補完する |
| `C-x b` / `C-x <right>` `C-x <left>` | 開いているバッファへ（`TAB` で補完。既定は前のバッファ）/ 次、前のバッファ |
| `C-x k` | バッファを閉じる。変更があれば聞く |
| `C-x C-c` | 変更のあるファイルを `C-x s` と同じく聞いてから終了する。それでも変更が残れば「Modified buffers exist; exit anyway?」と聞く |
| `C-x 2` `C-x 3` `C-x o` `C-x 0` `C-x 1` | ウィンドウ（nib のビュー）を上下・左右に分ける、次へ、閉じる、ほかを閉じる |
| `C-x =` | ポイントの文字と位置を出す（`Char: b (98, #o142, #x62) point=2 of 4 (25%) column=1`） |
| `M-.` / `M-,` | 定義へ（`lsp.definition`）/ 戻る |
| `M-x` | コマンドを名前で呼ぶ。Emacs の名前（`kill-line` など）と nib の名前（`lsp.definition`） |
| 貼り付け | ポイントに入れ、始めにマークを置く（`xterm-paste`）。isearch の中では検索の文字列に、ミニバッファでは欄に入れる |
| `C-h k` | キーが何をするかを出す |
| `F10` | コアのメニュー（Emacs ではメニューバー。`plugin.toml` の `menu-key`） |

## ミニバッファ

`M-x` や `C-x C-f` などの問いは、コアの入力欄で受ける（[plugin-api.md](plugin-api.md) の「入力欄」）。キーはすべてベースが読むので、キーボードマクロの中でも同じに動く。

- `C-a` `C-e` `C-f` `C-b` `C-d` `DEL` `M-f` `M-b` `M-d` `M-DEL` `C-k` `C-y`（キルを入れる）、`C-q`。
- `TAB` は候補の共通の部分まで補い、それ以上補えなければ候補を下に並べる。
- `M-p` `M-n`、上下は、その問いの履歴。
- `RET` で決め、`C-g` か `ESC ESC` でやめる。空のまま `RET` を押すと、ラベルの `(default …)` を使う。
- バッファの名前は、作業ディレクトリからのパス。外のファイルはファイル名。
- ほかのプラグインの入力欄（picker の検索欄など）でも、上の編集のキーが効く。
- 補完の一覧などが開いているときは、`C-n` `C-p` と上下で選び、`TAB` と `RET` で決め、`C-g` で閉じる。

## リーダー

`C-c` をプラグインのキーの置き場にする。プラグインの `[keys]` の `f` は `C-c f`、`c d` は `C-c c d`。Emacs でも `C-c` と文字 1 つは、ユーザーのためのキー。

## 設定

`plugins/emacs.toml` の `[settings.keys.global]` で上書きする。右辺はコマンドの名前か、Emacs のコマンドの名前（`forward-char`、`kill-line` など、`M-x` で呼べるもの）。表は前置きキーになり、組み込みの前置き（`C-x` など）の表に足される。

```toml
[settings.keys.global]
"C-x" = { "C-r" = "picker.files" }
"C-z" = "undo"
```

## 本物との比べ方

`tui/tests/compare.rs` が、`plugins/emacs/compare.toml` の各ケースのキーを `emacs --batch -Q` と nib に流し、テキスト、ポイント、有効なリージョンのマークを比べる（[base.md](base.md) の「どこまで再現するか」）。emacs がなければ飛ばす（CI では入れて、必ず走らせる）。

- キーは `execute-kbd-macro` で流す。キーボードマクロはコマンドのエラーや `C-g` の `quit` で止まるが、手で打ったキーはその先も続くので、止まったコマンドのあとのキーを流し直す。どこまで読んだかは、巻き戻される前に `signal-hook-function` で `executing-kbd-macro-index` を見て知る。isearch やミニバッファの途中の `C-g` も、これで比べられる。
- Emacs の `tab-width` は nib の既定にそろえて 4 にする。macOS の Emacs は `Home` `End` をバッファの端に割り当てる（ns-win）ので、ほかの OS と同じ行頭・行末に戻す。
- キーボードマクロは `execute-kbd-macro` の中で記録できないので、比べずに `plugins/emacs/tests/emacs.toml` で確かめる。ファイル、バッファ、ミニバッファの補完、リーダーも同じ。
- ミニバッファを開いたまま終わるキーは、Emacs が端末からの入力を待ってしまうので書かない（20 秒で打ち切って失敗にする）。
- 2026-09-28 の時点で 350 ケース。347 が GNU Emacs 31.1 と同じで、3 つは下の違い。
- 違うと分かっているケースは `differs` に理由を書く。同じになったら、テストが `differs` を外すように言う。

## Emacs との違い

- `undo` は nib の undo。Emacs のように「undo を undo する」ことはせず、redo は `C-?` で行う。リージョンの中だけの undo もない。
- `C-x C-u` と `C-x C-l` は、`emacs -Q` のように無効にしていない（Emacs は使ってよいかを聞く）。
- `TAB` は言語によらず `indent-relative`（Emacs の `fundamental-mode` と同じ）。タブの位置は nib の `indent` の幅ごと（Emacs は `tab-width` ごと）。
- 置き換える文字の `\,`（Lisp の式）と、パターンの後方参照は使えない（コアの正規表現にない）。
- `M-y` は、直前が yank のときだけ。Emacs 28 からの、キルリングから選んで入れる動きはない。
- `C-x =` は、ASCII でない文字の符号化の情報（`file ...`）を出さない。
- 端末では `C-/` と `C-7`、`C-SPC` と `C-2` が同じキーとして届くので、`C-7` は undo、`C-2` はマークになる（端末の Emacs と同じ）。
- `C-v` `M-v` は、ポイントを画面と同じ行数だけ動かす。
- 文字の幅は、tab を nib の `tab-width`、東アジアの全角を 2 として数える。
- 構文表はなく、`fundamental-mode` の標準の表に近い分け方をどの言語でも使う（単語は英数字、S 式の記号は英数字と `_-+*/&|<>=$%` など）。
- `C-h` は `C-h k` だけ。ほかのヘルプ、`M-:`、`M-;`、`C-x C-e`、dired、`C-x C-b` の一覧、`C-z` はない。
- キーボードマクロのカウンター（`C-x C-k` の仲間）はない。
